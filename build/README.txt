==========================================================
  MPI "My Hobby - Let's Play & Talk!"
  Bahasa Inggris SD Kelas III (Fase B) - Chapter 5: My Hobby
  PANDUAN CEPAT GURU
==========================================================

A. YANG DIBUTUHKAN
   - Laptop Windows dengan Google Chrome atau Microsoft Edge versi terbaru.
   - Proyektor / TV dan speaker.
   - TIDAK perlu internet dan TIDAK perlu instalasi.

B. CARA MEMBUKA
   1. Salin seluruh folder MPI ini ke laptop (jangan memindahkan file satu per satu).
   2. Klik dua kali "index.html". Jika terbuka di aplikasi lain, klik kanan
      index.html > Open with > Google Chrome / Microsoft Edge.
   3. Tekan tombol F untuk layar penuh, lalu klik START.

C. TOMBOL KEYBOARD
   Panah kanan / kiri  : scene berikutnya / sebelumnya
   Spasi               : putar suara utama scene
   N                   : buka/tutup Teacher Notes (langkah & Classroom English)
   M                   : Menu (lompat ke kegiatan mana pun)
   F                   : layar penuh
   Esc                 : tutup menu / catatan / kartu besar
   R                   : acak (kartu Charades, Point to..., spinner, Bima Says, soal berikutnya)
   T                   : mulai/jeda timer (Charades & Find Someone Who)
   1 / 2               : jawaban benar Team A / Team B (Charades)
   A / B / C           : jawaban kelas pada Quick Check

D. ALUR 1 PERTEMUAN (2 JP x 35 menit)
   Pendahuluan : Hello! -> Today I can...
   Inti        : Let's Learn -> Sing & Move -> Charades -> Let's Listen
                 -> Let's Talk -> Find Someone Who -> Quick Check
   Penutup     : My Reflection -> I Can Do More
   Waktu terbatas? Pakai Menu (M) untuk memilih kegiatan yang diperlukan saja,
   atau bagi menjadi 2 pertemuan.

E. TEACHER'S CORNER (khusus guru)
   Buka Menu (M), lalu TAHAN tombol "Teacher's Corner" selama 2 detik.
   Isinya: modul singkat, Classroom English bersuara, tips pelafalan,
   lembar observasi, bahan cetak, dan pemeriksa kelengkapan file.

F. LEMBAR OBSERVASI & DATA MURID
   - Nama dan skor yang diisi di lembar observasi tersimpan HANYA di browser
     laptop ini (tidak dikirim ke internet). Data tidak ikut pindah ke laptop lain.
   - Cetak dengan tombol "Cetak", lalu hapus dengan "Hapus semua data"
     (klik dua kali) setelah nilai dicatat di buku nilai.
   - Nama di kegiatan Find Someone Who dan angka refleksi TIDAK disimpan.

G. JIKA ADA MASALAH
   - Gambar tampil sebagai kotak bergaris putus-putus berisi nama file:
     file gambar tersebut belum ada di folder assets/. Cek daftar lengkapnya di
     Teacher's Corner > E. Unduhan Cetak > "Periksa kelengkapan file".
   - Muncul tulisan "Audio belum tersedia": file suara belum ada di
     assets/audio/. Guru dapat membacakan kalimatnya langsung.
   - Suara tidak terdengar: periksa kabel/volume speaker dan volume Windows.
   - Tampilan terlalu kecil/besar: tekan F (layar penuh). MPI menyesuaikan
     ukuran layar secara otomatis.
   - Tombol "Cetak" tidak membuka jendela: izinkan pop-up untuk halaman ini.
   - Font terlihat berbeda: letakkan file font di assets/fonts/
     (lihat assets/fonts/BACA-SAYA.txt). MPI tetap bisa dipakai tanpa font itu.

H. ISI FOLDER
   index.html         halaman utama (buka file ini)
   css/, js/, data/   tampilan, program, dan isi materi (jangan diubah)
   assets/            gambar (img/, anim/), suara (audio/), font (fonts/)
   print/             PDF bahan cetak: flashcard, kartu Charades, LKPD, refleksi, observasi
